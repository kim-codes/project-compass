# Project Compass 

Helping developers find their way into your project.

**Status: Work in progress**

A small developer experience tool that looks at a GitHub project (README), spots where developers might get stuck, and suggests ways to improve the getting started experience.

### how it would work 

enter a public GitHub repo (URL) and get an assessment back across three areas:

- **discover:** cab developers quickly understand what the project does?
- **start:** can they figure out how to get it running?
- **explore:** are there examples and resources to help them go further?
